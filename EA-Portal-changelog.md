For handover to Aswin. Newest entries at the top. Each entry lists the version, the file touched, and what changed, so it can be matched to the zip.

How to read it: "File" is the component in the prototype folder. "Changed" is what the user will see. "Dev note" is anything built differently that affects the real build.
